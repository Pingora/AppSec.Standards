# CS-1.1 Code Security Training

**Status:** Draft

## Control Objective

The objective of code security training is to support the knowledge and comprehension of standards designed to facilitate software that is developed free of security vulnerabilities, and to ensure that software development is done with security in mind.

Code security training educates developers about the most commonly exploited security vulnerabilities as related to the software they introduce, write, and/or review so that they can both fix existing vulnerabilities, and avoid creating vulnerable software in the first place.

## Control Validation

Proof of course completion by all software developers and vendors who write software. Line of business management is responsible for ensuring the developers in their area complete in a timely manner.

- Standard courses are deployed by Information Security Risk and Compliance and this training, or an alternative authorized by ISRC, must be completed on an at-least-annual basis by any Company developer who introduces code and/or reviews and authorizes introduction of code to the production environment.
- If the standard course is utilized, ISRC will produce reports. If the standard course is not utilized, reporting should be in the form of a report of learners who have completed training validated by the Information Security Risk and Compliance group.
