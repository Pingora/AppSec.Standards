# VM-1.3 DAST Recurrent Scanning

**Status:** Draft

## Control Objective

- Ensure that the company's people, processes, and technology systems are prepared to perform secure software development.
- Protecting all components of the company's software from tampering and unauthorized access.
- Producing well-secured software with minimal security vulnerabilities in its releases.
- Detecting potential security vulnerabilities before they are released to production systems.
- Continually detect DAST vulnerabilities in the company's systems.

## Control Validation

- DAST-scannable software applications should be scanned with a company-approved DAST scanning tool after every release.
- DAST-scannable software applications must be scanned, at a minimum quarterly (90 days), with a company-approved DAST scanning tool.
